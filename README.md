# 飯盒タイマー 🍚

キャンプやアウトドアでの飯盒炊飯をタイマーで管理するWebアプリです。

## 概要

飯盒でご飯を炊くときの「吸水」「強火」「弱火」「蒸らし」の各ステップをタイマーで管理できます。

## 機能

- ✅ **準備チェックリスト** - 米を研ぐ、水を入れるなどの確認項目
- ⏱️ **4段階タイマー** - 吸水(30分)→強火(5分)→弱火(10分)→蒸らし(15分)
- 🎛️ **時間カスタマイズ** - 各ステップの時間を調整可能
- 🚫 **ステップ無効化** - 不要なステップをスキップ可能
- 🎵 **通知音** - 各ステップ終了時にファンファーレ
- 📱 **レスポンシブ** - スマホでも使いやすいUI

## 使い方

1. 準備チェックリストをすべてチェック
2. 必要に応じて各ステップの時間を調整
3. 「スタート」ボタンでタイマー画面へ
4. 円環をタップして各ステップを開始
5. 各ステップ終了後に自動で次のステップへ

## ローカル実行

```bash
# リポジトリをクローン
git clone https://github.com/PeachGumi/hanngo-timer.git
cd hanngo-timer

# ブラウザで開く
open index.html
```
